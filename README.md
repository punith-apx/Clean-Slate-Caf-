# Clean Slate Café

A responsive café website built with semantic HTML, CSS and vanilla JavaScript. No build step or package dependencies are required.

## Run locally

From this directory, start any static file server. For example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

Deploy this directory as a static site on Cloudflare Pages. The project root is this directory and no build command is needed. Fonts and food photography load from external services; the page remains readable if those services are unavailable.

Opening hours, services and menu availability are labeled for café confirmation. Menu items are editable in `index.html`; no prices or customer testimonials have been invented.
